WEB-SLINGER APK PROJECT (with built-in HOST)
1) Upload ALL files of this folder to a new GitHub repository (keep the .github folder).
2) Repository > Actions > 'Build APK' > Run workflow.
3) When it is green: open the run > Artifacts > WebSlinger-APK > download, unzip, install app-debug.apk.
Playing together: host taps MULTIPLAYER > HOST (hotspot ON), friends join the hotspot, tap MULTIPLAYER > JOIN and type the code.
